# Level 2 / Level 3 — planned only

Level 2: administrator-level OCI lifecycle experiments, including identity, network, provisioning, monitoring, recovery and cleanup.

Level 3: experiments that treat AI as an architect, evaluating requirements, decisions, trade-offs, costs and evidence against agreed criteria.

Neither phase has begun. This directory contains no runnable infrastructure. See [the roadmap](../docs/roadmap.md) for prerequisites and evaluation boundaries. Level numbers are local project stages, not official Oracle certification levels.
